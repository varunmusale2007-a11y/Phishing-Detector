# 🛡️ Phishing URL Detector

A **Machine Learning-based web application** that analyzes URLs and detects whether they are **Safe** or **Potentially Phishing**.

## 🚀 Features

* 🔍 URL scanning and analysis
* 🤖 Machine Learning-based detection
* 🟢 Safe / 🔴 Phishing classification
* 📊 URL feature analysis
* 📱 Responsive design for mobile and desktop
* ⚡ Fast prediction

## 🛠️ Technologies

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python, Flask
* **ML:** Scikit-learn, Pandas, NumPy

## ⚙️ How to Run

```bash
git clone https://github.com/varunmusale-ally/phishing-url-detector.git
cd phishing-url-detector
pip install -r requirements.txt
python app.py
```

Open:

```text
http://127.0.0.1:5000
```

Live working on the website :  https://varunmusale2007-a11y.github.io/Phishing-Detector/

## 🧠 How It Works

```text
URL → Feature Extraction → ML Model → Prediction
                                      ↓
                              SAFE / PHISHING
```

## 🔐 Disclaimer

This project is developed for **educational and cybersecurity research purposes**. Detection results are predictions and should not be treated as a guarantee that a website is safe.
